# 📊2-1-1-Helpline Operations United Way San Antonio and Bexar County
## 📖 Project Overview
The goal of this project is to analyze regional caller patterns of the 2-1-1 Helpline operations. This project dives into how caller demographics and taxonomy needs vary across three regions (Alamo, Middle Rio Grande, Golden Crescent). 

Key tasks include:
* Cleaning and processing 3 datasets (Clients, Interactions, and Referrals)
* Determining critical variables necessary to answer the research question
* Conducting assessments (caller activity, caller demographics, and needs)

## 🔍 Primary Research Question
How do caller demographics and needs vary across the regions?

## 🛠️ Tools Used
* Python (Numpy, Matplotlib, Seaborn, Pandas, etc.)
* Excel
* Google Colab
* JMP Statistical Discovery

## 🚫 Data Access and NDA
This project was completed in partnership with United Way of San Antonio & Bexar County. Due to the confidentiality terms of the Non-Disclosure Agreement (NDA), no CSV or Excel data files from this project are uploaded to this repository. Only scripts and documentation are provided.
